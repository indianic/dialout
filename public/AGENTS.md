# public

## Purpose

Static assets for the PWA: icons, web manifest, and the service worker. Icons are regenerated by `scripts/generate-pwa-icons.js` — do not hand-edit the PNGs if you can regenerate them.

## Key Files

| File | Description |
|------|-------------|
| `manifest.webmanifest` | PWA manifest (name, icons, display). |
| `sw.js` | Service worker. |
| `favicon.svg` | Vector favicon. |
| `icon-192.png` / `icon-512.png` | PWA icons (generated). |
| `apple-touch-icon.png` | iOS home-screen icon (generated). |

## Subdirectories

None.

## For AI Agents

### Working In This Directory

- After changing the source mark, rerun `scripts/generate-pwa-icons.js` rather than editing PNGs.
- The same VAPID key pair must be used in dev and prod or existing web-push subscriptions stop working — that is env, not these files, but the PWA install surface lives here.

### Testing Requirements

Load `/manifest.webmanifest` and confirm icons resolve. No unit tests.

### Common Patterns

Keep filenames stable; the manifest and HTML reference them by path.

## Dependencies

### Internal
